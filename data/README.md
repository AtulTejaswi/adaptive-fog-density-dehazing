# Data

The repository never commits images.  Data is downloaded/generated by:

```bash
python scripts/download_data.py       # SOTS (RESIDE) -> data/downloads + data/SOTS
python scripts/download_rtts.py       # 72 real RTTS images -> data/RTTS
python scripts/prepare_data.py --no-download   # splits (SOTS + RTTS + sweeps)
```

## Real SOTS (RESIDE) layout
```
data/SOTS/indoor/hazy/1400_1.png
data/SOTS/indoor/gt/1400.png
data/SOTS/outdoor/hazy/0001_0.8_0.2.jpg
data/SOTS/outdoor/gt/0001.png
```
Automatic source: https://huggingface.co/datasets/desonglll/reside-SOTS (SOTS.zip).
If the download is blocked, place `SOTS.zip` in `data/downloads/` manually.

## Real RTTS (RESIDE-beta, used for the no-reference check)
The project uses **72 real-world hazy images** (no ground truth) from the RESIDE-beta
RTTS set, taken from the Hugging Face mirror `fuhao7i/RTTS` (Apache-2.0) which
contains the 4322 original RTTS photographs.  A fixed manifest
(`scripts/rtts_subset.txt`) selects the 72 files so results are reproducible:

```bash
python scripts/download_rtts.py        # -> data/RTTS/ (72 images)
python scripts/prepare_data.py --no-download
```

To use a different real-world set, drop any images into `data/RTTS/` (nested
folders are fine) and re-run `prepare_data.py`.  If `data/RTTS/` is empty, the
pipeline falls back to a synthetic RTTS-style set so the no-reference
evaluation still runs; `data/splits.json` records which source was used.

## What is committed
Only `data/splits.json` and this README are kept; `data/` images are gitignored.
Splits are deterministic for a fixed seed and can always be rebuilt.
