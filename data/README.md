# Data

The repository never commits images.  Data is downloaded/generated by:

```bash
python scripts/download_data.py       # SOTS (RESIDE) -> data/downloads + data/SOTS
python scripts/prepare_data.py        # splits + RTTS-style fallback
```

## Real SOTS (RESIDE) layout
```
data/SOTS/indoor/hazy/1400_1.png
data/SOTS/indoor/gt/1400.png
data/SOTS/outdoor/hazy/0001_0.8_0.2.jpg
data/SOTS/outdoor/gt/0001.png
```
Automatic source: https://huggingface.co/datasets/desonglll/reside-SOTS (SOTS.zip).
If the download is blocked, place `SOTS.zip` in `data/downloads/` manually.

## Real RTTS (optional)
Put real-world hazy images (no ground truth) in `data/RTTS/`.  Every image is
used as-is in the `test_rtts` split.  If the folder is absent, a synthetic
RTTS-style set is generated so the no-reference evaluation still runs.

## What is committed
Only `data/splits.json` is small enough to keep; `data/` images are gitignored.
Splits are deterministic for a fixed seed and can always be rebuilt.
